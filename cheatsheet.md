# Cheatsheet — Simon's judgment on one page

## Decision rules

| When… | Do… | Because (Simon) |
|---|---|---|
| Choosing where to spend management effort | Price first, then variable cost, volume, fixed cost | +5 % each → profit +50 / +30 / +20 / +15 % (ch05) |
| A price cut or discount is proposed | Compute break-even volume = cut ÷ (contribution margin − cut); reject if it exceeds what elasticity 1.3–3 delivers | 20 % cut at 40 % margin needs +100 % volume (ch05) |
| Forced to lose 5 % price or 5 % volume | Lose the volume | −50 % vs −20 % profit (ch09) |
| A customer demands a concession | Give goods, scope, credit or free months, never a lower nominal price; label it temporary | Customer values it at retail, you pay variable cost, it expires itself (ch09) |
| Costs, tax, FX or willingness to pay shift by X | Move price by X/2 | Midpoint rule: p* = ½ (p_max + variable cost) (ch06) |
| You deliver 20 % more value than rivals | Charge ~10 % more | Share the value fifty-fifty (ch06) |
| Insiders say +10 % price loses 50 % volume | Don't raise (elasticity 5); ask "why?" and "what happens next?" | Expert-judgment method (ch06) |
| Elasticity near your price is < 1 | You are below the profit optimum; raise | Profit-max requires elasticity > 1; elasticity = 1 is the revenue peak, often a loss (ch06) |
| Adding a second price point | Name the fence first; simulate migration of high-WTP buyers | No fence → below one-price profit (−43 %) (ch07) |
| Quoting volume discounts as seller | Incremental, never full-volume | Same table, 2× profit (ch07) |
| A period has low demand | Discount only if measured elasticity there is high; prefer one deep slot to many shallow ones | Empty Sunday garage at €1 stayed empty (ch07) |
| Launching a new product | Penetrate if experience good + word of mouth + scale effects; skim if price signals prestige, capacity limited, costs fall with volume | Lexus vs iPhone (ch07) |
| Sold out on day one | Treat as evidence the price was too low | Audi Q7, Playmobil, Asus (ch07) |
| Real +X % performance won't survive a +X % list price | Change the metric so usage pays for it | Michelin per mile (ch08) |
| Considering a flat rate | Only if consumption is naturally capped; simulate heavy-user tail | Flat rates cap revenue forever (ch08) |
| Running freemium | Optimize the free/paid gap, not the price | Elasticity ≈ 1; ~20 % upside from structure (ch08) |
| Need a price increase in a competitive market | Cut discounts via commission tied to discount level, shown live | 16 % → 14 % = +2 % price, no volume loss (ch05, ch08) |
| Need to pass on costs | Indexed surcharge on a low-attention element | Fuel surcharge with <1 % margins raised returns 30 % (ch08) |
| Tempted to charge for something felt "already paid" | Don't, without research | Bank of America $5 debit fee (ch08) |
| A pool of value is being split in negotiation | Know your weight-based share, negotiate above it | Selten game +20 % (ch01) |
| Buyers can't judge quality and a low price blocks sales | Re-bundle richer at a higher price | Cloud software $19.90 case (ch03) |
| Building a price menu | Put a high anchor first; make the intended tier the middle; offer three | +23–28 % revenue per customer (ch03) |
| Under inflation | Raise at least with inflation, small regular steps, start early | Relative cuts vanish in the noise (ch06) |
| Presenting a pricing program to owners | State it as Δprofit × PE | +2 % price ≈ +26.7 % market cap (ch10) |
| Setting an approval threshold or floor | Assume every deal lands exactly there | 20 % floor → 20.1 % deals (ch10) |
| CEO invited to a customer negotiation | Decline | Each visit leaked concessions (ch10) |

## Thresholds & defaults

| Item | Value |
|---|---|
| Price elasticity, typical | 1.3–3, median ≈ 2 (ch05) |
| Advertising / sales-force elasticity | 0.05–0.1 / 0.2–0.35 → 1 % price ≈ 10–20 % ad budget ≈ 7–8 % sales force (ch05) |
| Δprofit from a price change, volume constant | ≈ Δprice % ÷ net margin % (ch05) |
| Uniform price captures | ~50 % of the profit triangle (linear demand) (ch07) |
| Gain from 2nd / 3rd price tier | +33 % / +12.5 % contribution (power tool) (ch07) |
| Two-part tariff: perceived vs real discount | BahnCard 50: 50 % perceived, <30 % real (ch02) |
| LEA price gap | ~20 % below lead brand (ch04) |
| Ultra-low segment | 50–70 % below developed-market low (ch04) |
| Hidden Champions | 10–15 % above market, 2.4× industry returns (ch10) |
| Upward-sloping (prestige) demand | ~5 % of cases (ch03) |
| Promotions share where discounting hits what would have sold anyway | > ~50 % of category sales (ch02) |
| Sustained +2 % price → market cap | +26.7 % at PE ~18 (ch10) |

## Tells & smells

- **Share, revenue, utilization or traffic is the operative target** → pricing will drift toward zero (ch05).
- **"We'll make it up on volume"** → nobody computed break-even (ch05).
- **A volume spike after a promotion** → check the next three months for the mirror-image dip (ch05).
- **Deals cluster at the floor** → the floor is the price (ch10).
- **Rate card set from competitors' public rates** → you inherited their cost structure (ch06).
- **Margin target calibrated backwards from a chosen price** → cost-plus wearing a market-based label; no value input (ch06).
- **Premium claim, price below the benchmark** → mixed quality signal (ch03, ch04).
- **Discount grid deeper than the floor allows** → one of the two is theater (ch10).
- **Payment-term discount above the financing cost** → price given away, not time (ch09).
- **Only one price, one metric, one option in the proposal** → half the triangle untouched, no anchor (ch03, ch07).
- **Nobody makes money in a concentrated industry** → capacity, not price (ch09).
- **Positioning built on a discount slogan** → no exit path (ch10).
